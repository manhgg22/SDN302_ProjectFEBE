# SDN302 Project — Frontend & Backend

Đồ án môn SDN302. Repo gộp cả hai phần trong một chỗ.

## Cấu trúc

```
client-fe/   # frontend React
clinet-be/   # backend Node/Express
```

> Thư mục backend bị gõ nhầm thành `clinet-be` (đúng ra là `client-be`). Giữ nguyên để không làm hỏng đường dẫn đang dùng.

## Chạy

```bash
cd clinet-be && npm install && npm start
cd client-fe && npm install && npm start
```
